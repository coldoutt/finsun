## О проекте

FinSun помогает собрать личные финансы в одном понятном интерфейсе. Приложение объединяет учёт активов, месячные снимки капитала, финансовую историю и бюджет, чтобы видеть не только текущую сумму, но и то, как она меняется со временем.

## Возможности

### Дашборд

- Общая стоимость активов и изменение капитала за месяц и год.
- Интерактивный график динамики за 6 месяцев, 1 год, 3 года, 5 лет или за всё время.
- Детальная информация о каждом месяце при наведении на график.
- Структура портфеля по категориям и доля каждой категории.
- Актуальные курсы доллара и евро к рублю, а также годовая инфляция.

### Активы

- Учёт активов по разделам: банки, наличные, крипта, биржа, имущество и прочее.
- Добавление, удаление и перетаскивание активов внутри раздела.
- Сохранение отдельного снимка портфеля за каждый месяц.
- Автоматическое заполнение нового месяца данными предыдущего.
- Поиск валют по ISO-коду или названию и пересчёт их стоимости в рубли.
- Автоматическая загрузка курса выбранной валюты с возможностью ручной корректировки.
- Поиск криптовалют и расчёт рублёвой стоимости по количеству и цене.

### Бюджет

- Планирование доходов и расходов на выбранный месяц.
- Сравнение плановых и фактических значений.
- Автоматический расчёт разницы и свободного остатка.
- Добавление, удаление и перестановка статей бюджета.
- Копирование бюджета предыдущего месяца.

### История

- Просмотр сохранённых месяцев с группировкой по годам.
- Сравнение стоимости активов и изменений между периодами.
- Удаление ошибочных или ненужных записей.
- Использование всей истории для построения графика капитала.

### Профиль и персонализация

- Регистрация, вход и восстановление пароля.
- Персональные финансовые данные для каждого пользователя.
- Редактирование имени, фамилии и фотографии профиля.
- Светлая и тёмная темы.
- Адаптивный интерфейс для компьютера и телефона.
- Сохранение выбранной вкладки и раздела активов после обновления страницы.

## Данные и безопасность

FinSun работает как статическое веб-приложение на GitHub Pages и обращается к Supabase напрямую из браузера:

- **Supabase Auth** отвечает за регистрацию, вход и пользовательские сессии.
- **PostgreSQL** хранит профили, активы, историю и бюджеты.
- **Supabase Storage** хранит фотографии профиля.
- **Row Level Security** ограничивает доступ к данным идентификатором текущего пользователя.

Пароли не хранятся в репозитории или коде приложения. GitHub Pages раздаёт только интерфейс и не является хранилищем персональных финансовых данных.

## Источники данных

- **Банк России** — курсы доллара и евро к рублю, официальная инфляция.
- **Frankfurter API** — список мировых валют и автоматические валютные курсы.
- **CoinPaprika API** — каталог криптовалют и рыночные данные.

## Локальный запуск

```bash
npm run web:start
```

После запуска приложение доступно по адресу:

```text
http://localhost:5500
```

Для обновления статических показателей Банка России:

```bash
npm run metrics:update
```
